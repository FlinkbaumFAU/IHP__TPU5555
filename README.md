# IHP__TPU5555

Hyperdimensional-computing (HDC) classifier chip with an SPI host interface, in IHP SG13CMOS5L.
It is a complete padded design (2.4 mm × 2.0 mm, 22 IO pads, 6 SRAM macros) for the IHP Open-Silicon MPW,
category **Digital / TPU** (ML accelerator).

- `doc/`: datasheet, specification, TRL assessment, `info.json`
- `dependencies/`: none (IO cells, SRAM macros and standard cells come from the IHP Open PDK)
- `release/v.1.0.0/`: final GDS (`TPU5555.gds`, seal ring and fill included) and netlists
- `TPU5555-main/`: RTL, constraints, LibreLane flow, implementation views, verification reports
- `measurements/v.1.0.0/`: empty until silicon is available
